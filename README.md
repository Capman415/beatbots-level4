# beatbots-level4 (redirect)

The Level 4 app was renamed and now lives at:

https://capman415.github.io/steadybots-level4/

This repository only serves a tiny GitHub Pages site that forwards the old
`/beatbots-level4/` URL (including subpaths, query strings, and hashes) to the
new address, and that unregisters leftover service workers from classroom devices.
